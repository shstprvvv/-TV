# КЛИК TV — обновления Android TV

Актуальная версия: **1.2.1**. [Скачать APK](https://raw.githubusercontent.com/shstprvvv/-TV/main/apk/klik-tv-1.2.1.apk).

Здесь размещены только установочные APK и файл версии. Приложение работает на Android 10+; управление с пульта.

## Установка

Скачать APK из папки `apk`, открыть на приставке, разрешить установку из выбранного источника и подтвердить установку.
При переходе с прежней тестовой debug-сборки потребуется один раз удалить её: production APK имеет отдельную постоянную подпись. Локальный кэш каналов будет удалён и загрузится заново.

## Обновления

При каждом возвращении в приложение оно проверяет `stable.json`.
Если опубликованный versionCode больше установленного, просмотр закрывается до обновления.
Приложение скачивает APK, проверяет SHA-256, размер, имя пакета, версию и совпадение подписи с установленной копией.
Пользователь нажимает «Установить» и подтверждает действие в системном установщике Android.

При временной ошибке проверки доступ разрешён, если обязательное обновление не было обнаружено ранее. Уже обнаруженное обновление остаётся обязательным после перезапуска и без интернета.

## Выпуск новой версии

1. Собрать и проверить новый universal release APK с тем же постоянным ключом подписи и большим versionCode.
2. Добавить APK под новым именем в `apk/`. Старый APK не заменять другим содержимым.
3. Обновить `stable.json`: versionCode, versionName, apkUrl, sha256, sizeBytes и notes.
4. Опубликовать APK и JSON одним коммитом в ветку `main`.

Менять только номер в JSON нельзя: значения должны соответствовать APK. Ошибочная обязательная версия может заблокировать просмотр. При необходимости отмены релиза вернуть JSON предыдущего исправного релиза; клиенты подхватят его при следующей успешной проверке.

Ключ подписи и его пароли не должны попадать в этот репозиторий. Учётная запись GitHub не встроена в приложение.

Проверка обновлений не является системой оплаты или защиты подписки.
